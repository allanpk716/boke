## ④ 实验设计（全套 6 个，每个有判据与止损）

### E1 同语言换声 ABX —— **总闸，整个方向的 go/no-go**

- **假设**：分离→克隆→回混后，背景不穿帮（听不出哪个是加工片）。
- **方法**：zh→zh（国产剧，CosyVoice3 克隆原演员音色重说台词）+ en→en（Blender/海外剧）两条；流程 = Mel-Roformer 提对白（**波形相减**产背景床）→ 克隆配音逐句填窗 → loudnorm 配平 → 背景床回混 → crossfade。
- **指标**：ABX 盲听（协议见 ⑤）。辅助客观量：背景轨 bleed 指数 = Whisper 在背景轨的听写可懂度 / 在原混的可懂度（越低越干净）。
- **判据**：ABX 识别率与 50% 无显著差异（二项检验，16~20 试次/条件）= **PASS**；50~65% = 边缘（进 E1' 找穿帮源再战一轮）；**>65% = FAIL → 方向止损**，写报告收档。
- **产出**：`e1_separation/abx_round1.md` + R1 盲听。

### E1' 分离方法横评 —— 找 E1 的最优配置

- **对比**（同一批片段）：Mel-Roformer 二分 / BandIt-v2 三分 / SDX'23 冠军三招（音乐人声模型提对白→相减→再分 M/FX）/ 相减纪律 vs 模型第二输出。
- **指标**：真值轨 museval SDR/SI-SDR（Blender 分轨合成 mixture）；真实轨 bleed 指数 + 非对白窗背景与原混逐样本一致性；R2 盲听偏好（两两对比选更自然的）。
- **判据**：选出"E1 复跑配置"；量化相减纪律的实测收益（或证伪）。
- **产出**：`e1_separation/compare.md` + R2 盲听。

### E3 时长三段式（**双向**）+ 变速阈值定标

- **假设**：LLM 音节预算（多候选）→ TTS 语速 → atempo 兜底，能塞进原句窗且不 sounding rushed。
- **方法**：真实轨字幕窗上跑 zh→en 与 en→zh 两向；候选 3~5 个按时长估挑；CosyVoice `speed` 微调，超窗句换 ZipVoice `--speed`；atempo 兜底。
- **指标**：进窗率（±10%）、atempo>1.15 使用率、回炉率；**变速可闻阈值定标**（同一句按 1.0/1.15/1.3/1.5 合成，R3 盲听找拐点——校准主线 align_mix 的 MAX_TEMPO=1.15 这个拍脑袋值，本身是研究副产品）。
- **判据**：≥85% 进窗、>1.15 使用率 ≤10%；定标出本项目 TTS 栈的真实阈值。
- **产出**：`e3_timing_remix/fit_stats.md` + R3 盲听。

### E2 伪重叠 TSE + 声纹自检门

- **假设**：重叠段 TSE 可兜底，且"提错人"事故能被声纹门拦住。
- **方法**：构造轨（分同/异性别两层）；TSE 候选 X-TF-GridNet（研究代码）与 NeMo `tse_sortformer_4spk-v1`（工程就绪）至少跑一个，另一个视时间。
- **指标**：SI-SDR（有真值）；**提错人率**（TSE 输出 vs 声纹档案 embedding cosine，阈值用调研04 的自校准法——拦截率与**漏检率**分开记）；TSE 产物克隆 vs 干净参考音克隆的音色相似度对比（embedding cosine + 抽查试听）。
- **判据**：**漏检率 = 0 是一票否决**（出现即该路降级人工，写死在结论里）；SI-SDR 分层报告，同性别段单独统计。
- **产出**：`e2_overlap/tse_eval.md`（自动指标为主，无需专门盲听轮）。

### E4 5.1 中置路线（条件实验）

- **前提**：Blender 发行版核实到 5.1 声源（D0 核实；B 站流基本是立体声，DnR 是 44.1k 立体声，都不行）。
- **方法**：`pan=mono|c0=FC` 抽中置 → 对白纯度对比（C 通道 ASR WER vs 分离对白轨 ASR WER，以字幕为参照）+ C 通道音乐能量占比；E1 配置在 5.1 下复跑一小组 ABX。
- **判据**：C 通道对白纯度显著优于分离模型 → 结论"有 5.1 必走中置"写进报告。
- **产出**：`e4_center51/center_eval.md`。若 D0 核实不到 5.1 素材：E4 降级为"文献结论采信（05 篇 §⑦），遇到片源再补"，不占排期。

### E3b 端到端全链（双向）

- **假设**：分离+克隆+翻译+时长+回混全链能听。
- **方法**：真实轨每部剧选 2~3 分钟对话密集段，zh→en 与 en→zh 各出一版成片；用 E1'/E3 选出的最优配置。
- **指标**：自然度 5 分制（R4 综合试听，含背景穿帮、音色像不像、节奏赶不赶三个分项）；逐句响度配平误差（LUFS 差 vs 原对白轨）。
- **判据**：自然度 ≥3.5、LUFS 差 ≤±2、无"背景穿帮"一票投诉。
- **产出**：`e3_timing_remix/e2e_demo/`（成片）+ R4 盲听。

### ⑤ 盲听协议（ABX 细则）

- 听者：用户本人（N=1，研究门用途足够，不冒充统计显著的人群结论）。
- A/B/X 三段式强制选择：A=原片、B=加工片（顺序随机化）、X=A 或 B 随机；每条件 16~20 试次；结果对 50% 做二项检验。
- 偏好测试（E1'）：两两对比选"背景更自然/穿帮更少"。
- 每轮时长 15~20 分钟，戴耳机，环境安静；与主线核对门操作分开约，不叠加。
- 试次清单与结果原始数据落 `lab/drama/results/abx/`（json），报告只引数字。
