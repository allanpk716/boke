## 目录约定

```
boke/
├── in/                  # 待处理视频（软链或拷入）
├── work/<video_id>/     # 中间产物（audio.wav / ocr.srt / diar.rttm / tagged.srt / ...）
├── out/<video_id>.m4a   # 最终音频
├── refs/                # 音色参考音频
├── voices.yaml          # 音色映射配置
├── src/                 # 流水线代码
└── docs/research/       # 2026-09 调研交接包（01 需求 / 02 组件验证 / 03 全景底稿）
```
