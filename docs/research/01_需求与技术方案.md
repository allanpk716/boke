# 01 需求与技术方案 — 视频中文配音流水线

- 日期：2026-09-23
- 本文是开发蓝本：需求收敛结果 + 整体架构 + 核心自研层设计 + MVP 计划
- 组件的最终选型以 `02_组件选型与效果验证.md` 为准（本文写初步选型）

---

## 1. 需求（已三轮收敛，定稿）

### 1.1 场景

- 输入：采访类节目视频。**原声是外语（可能单视频混多语言），画面带中文硬字幕**（官方/汉化中字，烧在画面里不可关闭）
- 输出：**中文配音独立音频**（wav/mp3/m4a），通勤路上听。视频为可选副产物
- 量级：批量处理，一期一个视频，时长 30~120 分钟

### 1.2 功能需求清单

| # | 需求 | 说明 |
|---|---|---|
| R1 | 从画面提取中文硬字幕 → 文字稿+时间轴 | OCR 路线，官方字幕文本准、帧级时间轴；**文字稿唯一来源**（不用 ASR 听写） |
| R2 | 从音频分出说话人 | 声纹 diarization；**语言无关**，外语原声直接跑 |
| R3 | 每条字幕归属到说话人 | 时间轴匹配（核心自研层，见 §4）；产出"谁说了哪句" |
| R4 | 按说话人分音色做中文 TTS | 音色映射表机制，见 §5 |
| R5 | 指定某人的真实中文声音 | 用他说中文的录音做**同语言零样本克隆**（中文参考念中文稿=克隆最优档） |
| R6 | 配音时长贴住原句节奏 | 时长对齐三招（限长/变速≤1.15x/借静音） |
| R7 | （可选）BGM 垫底 | 人声分离产 BGM 轨，压 -8~-12dB 混回；可关闭 |
| R8 | 说话稿按人区分的文本产物 | 按人分稿 md/SRT（顺带产物） |
| R9 | 无翻译环节 | 字幕已是中文；若未来遇到外文字幕视频，翻译作为备选扩展（见 03 底稿模块 5） |

### 1.3 非需求（明确不做）

- 不做视频字幕烧录/合成视频（交付物是音轨）
- 不做实时/流式（离线批处理）
- 不做视频下载（输入是本地文件；下载用户自行解决）
- 不做说话人"识名"（diarization 只给匿名 1号/2号，人工指认，不做人声检索名人库）

## 2. 整体架构

```
视频文件（外语原声 + 中文硬字幕）
  │
  ├─[A] ffmpeg 抽音轨（本机）
  │
  ├─[B] OCR 中文字幕（3090）
  │      首选自建：OpenCV 抽帧(2-4fps) → 底部ROI裁剪 → PaddleOCR PP-OCRv4/v5 中文
  │              → 相邻帧相似度合并成行 → ocr.srt（每条 [t0, t1, 中文文本]）
  │      备选：timminator/VideOCR（CLI 可批处理，活跃维护）
  │      ⚠ VSE 不用（时间轴 issue 贯穿五年，见 02 篇 §1；仅留作 GUI 交互抽查）
  │
  ├─[C] pyannote 声纹分人（3090，模型 speaker-diarization-community-1）
  │      默认原始音轨直喂（BGM 重时改喂人声分离后的人声轨）→ 说话人时间段 [s0, s1, SPK_xx]
  │
  ├─[D] 【核心自研】时间窗归人脚本（本机，~50 行）
  │      字幕条 × 说话人段 求交集 → 重叠占比投票 → 归属 + 置信度
  │      → tagged.srt（带 [SPK] 标签）
  │      → per-speaker.md（按人分稿）
  │      → review.csv（低置信度人工复核清单）
  │
  ├─[E] 人工环节（一次性，每期约 5 分钟）
  │      E1 听 D 输出的每人样本 10 秒 → 指认谁是谁 → 填音色映射表
  │      E2 过一遍 review.csv 低置信度行
  │
  ├─[F] TTS 合成（3090/4090）
  │      按映射表：SPK→预设音色 / 克隆音色（参考音频来自音色库）
  │      逐句合成 → 时长对齐三招
  │
  ├─[G]（可选）audio-separator 分离（4090）→ bgm.wav
  │
  └─[H] 混音导出（本机 ffmpeg）
         配音轨（+bgm 压低垫底）→ loudnorm → m4a/mp3
```

**关键设计决策及理由：**

| 决策 | 理由 |
|---|---|
| OCR 而非 ASR 拿文字稿 | 字幕已是中文=现成配音稿；官方字幕零错词；绕开 whisper 混语言大坑（30 秒窗单语言、开头误判，见 03 底稿模块 3） |
| diarization 默认喂原始音轨 | pyannote 在带噪数据上训练，DSP 降噪反而推高分错率（pyannote #1053 实证，针对 noise-reduce 类）；注意源分离≠DSP降噪——BGM 重的采访可先过人声分离再喂（02 篇 §2 失败模式同此口径） |
| 时间轴天然零偏移 | 字幕时间戳（画面）和说话人时间戳（音轨）来自同一视频文件，同源无偏移；不像外挂字幕要做偏移校准 |
| 无翻译环节 | 字幕已中文；省掉 LLM API 依赖和"译文膨胀"的半个问题（但中文稿 TTS 读超时仍存在，R6 仍需要） |

## 3. 各环节初步选型（最终以 02 篇为准）

| 环节 | 选型（已经 02 篇效果验证） | 跑在哪 |
|---|---|---|
| B OCR | **自建**：抽帧 + PaddleOCR PP-OCRv4/v5 中文（嫌 Paddle 环境烦换 RapidOCR=同模型 ONNX 版）；备选 VideOCR CLI；~~VSE~~（时间轴 issue 持续五年，避开） | 3090 |
| C 分人 | **pyannote speaker-diarization-community-1**（11/12 基准超 3.1，中文集全升；HF gated 免费领 token） | 3090 |
| F TTS 克隆 | **主：Fun-CosyVoice3-0.5B-2512（+RL 权重）**（中文 CER 0.81/相似度 77.4，开源第一档，Apache-2.0，显存 4-5GB，单句≤50字）；副① IndexTTS-2.5（独家精确时长控制，超时塞窗刚需时用，慢 3-5 倍）；副② GPT-SoVITS v2ProPlus（高频人物 >1min 素材微调，相似度口碑第一） | 3090/4090 |
| F TTS 预设 | **edge-tts**（免费自然，403 已修复剩偶发，需重试+降级）+ CosyVoice 内置音色兜底；本地轻量备选 Kokoro v1.1-zh（⚠ 固定音色池，**无克隆能力**） | API/本地 |
| G 分离 | **audio-separator + Mel-Roformer**（`vocals_mel_band_roformer.ckpt` SDR 12.6 库内最高；混响明显再加温和去混响）；~~htdemucs/MDX23C~~（低约 2dB 已被替代） | 4090 |
| H 整合 | **自建轻管道**（CosyVoice 服务 + Python 合成循环 + ffmpeg 拼接混音）；SmartSub 降级为对照品/应急 GUI（它只能吃 ASR 字幕吃不了 OCR 字幕，黑盒不可编程，见 02 篇 §6） | 本机 |
| 备选 ASR 线 | WhisperX + faster-whisper large-v3（RTF 0.08@3090，词级时间戳，默认已接 community-1） | 3090 |

**为什么直接自建、不走 SmartSub**（02 篇核实后定案）：SmartSub v3.7 虽已内置"说话人识别+按角色配音"，但字幕源只能 ASR——**吃不了我们的 OCR 字幕**（我们的主路线根基）；归人策略、时长对齐细节不可编程；无批量 API。而自建管道五段全是 pip 级依赖，替代成本约 1-2 人日，全可控。SmartSub 的"行级试听+重生成"交互值得抄进我们的 review 界面。

## 4. 核心自研层：时间窗归人算法

**已核实：无开源先例**（pyannote 官方教程只做"diarization+ASR 转写"配对；学术界只有电视剧视听说话人分离研究）。逻辑简单，自己写。

### 4.1 算法

```python
# 输入：
#   subs   = [(t0, t1, text), ...]        # 来自 ocr.srt
#   spkseg = [(s0, s1, spk_id), ...]      # 来自 pyannote（合并同说话人相邻段）
# 输出：
#   tagged.srt / per-speaker.md / review.csv

for (t0, t1, text) in subs:
    overlap[k] = sum( len(intersect([t0,t1], [s0,s1])) for (s0,s1,k) in spkseg )
    winner = argmax(overlap)
    conf   = overlap[winner] / (t1 - t0)      # 置信度
    tag(sub, winner, conf)

# conf < 0.6 → 进 review.csv（人工听一遍两可选择）
```

### 4.2 边界情况与对策

| 情况 | 现象 | 对策 |
|---|---|---|
| 一条字幕盖两人（抢话） | 重叠比例接近五五开 | 置信度筛选进 review.csv；接受"归给占时更长者"的近似 |
| 语气附和（嗯/对）无字幕条 | 音频有人声、无文本 | 不处理——没文本就不配音，无影响 |
| OCR 漏检/多检 | 字幕条缺失或台标误检 | VSE 有过滤；漏检导致该句无配音（原声漏掉），多检进 review |
| diarization 段碎（同一说话人被切碎） | 投票被干扰 | pyannote 输出先做相邻同说话人段合并 |
| 两人音色接近（同性亲属声） | 分人本身错 | 无解，人工指认环节发现后整段手工修 |

### 4.3 验收标准（第一步验证实验）

拿一期典型视频：OCR + 分人 + 归人跑完后，随机抽 20 条字幕人工听原声核对 → **归属准确率 ≥ 90% 且低置信度条目占比 ≤ 15%** 即通过；不达标先试 Sortformer，再不达标分析失败模式再议。

## 5. 音色映射表设计

```yaml
# voices.yaml —— 全局音色库 + 每期映射
library:                      # 攒库：常客每人一条，一次建立反复使用
  nvda_huang:                 # 库名（自起名）
    type: clone
    engine: cosyvoice         # 或 gptsovits / zipvoice
    ref_audio: refs/huang_chinese_30s.wav   # 他说中文的干净录音 10s~1min
    note: "某常客，中文流利"               # 备注是谁
  preset_male_01:
    type: preset
    engine: kokoro
    voice: zf_xiaoxiao        # 预设音色名

episode_map:                  # 每期：diarization 匿名说话人 → 音色
  file: interview_20260923.mp4
  map:
    SPK_00: { voice: preset_male_01, who: 主持人 }   # 人工指认后填
    SPK_01: { voice: nvda_huang,     who: 嘉宾黄某 }
```

**参考音频要求**（SmartSub 内置质检项，自建也照此校验）：单人独白、无 BGM（必要时先过人声分离）、无削波、信噪比足够、时长 10s~1min。

**克隆路线分级**：
1. 零样本同语言克隆（默认）：参考音频=目标人说中文 → CosyVoice/GPT-SoVITS/ZipVoice 直接可用
2. 微调升级（仅高频人物）：素材 >1min → GPT-SoVITS 微调，相似度更高
3. 跨语言克隆（本方案用不上）：参考是外语录音——已明确避免，同语言效果最优

**合规边界**：克隆音频自用（通勤听）无碍；**不得公开发布/传播**，有声音冒充法律风险。开发时建议在导出物里留原声人声指纹标记（文件名后缀即可），防误传播。

## 6. MVP 计划

| 阶段 | 内容 | 工作量 | 出口条件 |
|---|---|---|---|
| M0 验证实验 | 一期视频：OCR 管线 + pyannote + 归人脚本，人工核对 | 0.5~1 天 | §4.3 验收标准 |
| M1 端到端 | TTS 接入（方案甲 SmartSub 或方案乙轻管道）、映射表、混音导出 | 1~2 天 | 产出一个能听的完整 m4a |
| M2 批量化 | 目录监视/批量脚本、失败重试、日志、音色库管理 | 1~2 天 | 一晚上批量跑 5 期不崩 |
| M3 打磨 | BGM 垫底开关、loudnorm 响度统一、review 流程顺滑化、时长对齐调参 | 1~2 天 | 通勤实际听一周的体验反馈 |

总计 MVP 5~8 人日（与 03 底稿估计一致）。

**风险与预案：**

| 风险 | 预案 |
|---|---|
| 归人准确率不达标 | 升级 Sortformer（重叠专攻，限 4 人正好）；仍不行缩短视频单位（按段落切） |
| 抢话太多导致 review 清单爆炸 | review 界面做成"一键听原声+二选一"；实在多就接受错归属（听感影响有限） |
| OCR 环境坑（Paddle-GPU 与 CUDA 强绑定）/特殊字幕漏检 | 换 RapidOCR（同模型 ONNX 版 pip 即装）或 VideOCR；最坏走 ASR 备选线 |
| TTS 中文克隆不像 | 换引擎（02 篇横评备用）；预设音色兜底（不克隆，稳定优先） |
| 中文稿 TTS 读超时 | 限长（中文语速约 4~5 字/秒，按时间窗算字数）→ 变速 ≤1.15x → 借静音 |

## 7. 数据与产物目录约定（建议）

```
project/
├── in/                  # 待处理视频
├── work/<video_id>/     # 中间产物
│   ├── audio.wav        # 抽出的音轨
│   ├── ocr.srt          # OCR 字幕
│   ├── diar.rttm        # 分人结果
│   ├── tagged.srt       # 归人后（核心产物）
│   ├── per-speaker.md   # 按人分稿
│   ├── review.csv       # 待人工复核
│   ├── tts/*.wav        # 逐句合成
│   └── bgm.wav          # 分离出的伴奏轨（可选）
├── out/<video_id>.m4a   # 最终音频
├── refs/                # 音色库参考音频
└── voices.yaml          # 音色映射配置
```
