## 需求要点（详见 01）

1. 字幕已是中文 → **无翻译环节**，OCR 出的文本直接当配音稿
2. 原声是外语没关系：声纹分人（diarization）认嗓音不认语言
3. 核心自研 = 字幕时间轴 × 说话人时间段的对齐归人（约 50 行，无开源先例）
4. 说话人可指定音色：支持"某人的中文录音→同语言克隆"（中文声音念中文稿，克隆最优档）
5. 最终交付物是**独立音频**（音轨），不是视频；BGM 可选垫底

## 硬件分工

- 本机 Win10：胶水脚本、SmartSub（如果用它）
- 3090 (24GB)：OCR、声纹分人、TTS 推理
- 4090x2 (48GB)：批量分离、批量 TTS、（可选）音色微调
- LLM API：本方案已不需要（无翻译环节）

## 第一步（半天级验证实验）

拿一期典型采访视频跑通前半程：OCR 提字幕（自建抽帧+PaddleOCR，备选 VideOCR）→ pyannote community-1 分人 → 匹配脚本归人 → 人工听 5 个片段核对归属准确率。这一步验证全项目命门，通了之后全是拼装。**注意：VSE（star 最高的那个）经验证后弃用**——时间轴不准的 issue 持续五年，对"时间窗归人"是毒药，理由见 02 篇。
