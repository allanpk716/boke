# Spec — 影视剧配音研究评估（lab/drama）夜间实施

> 来源：lab/drama/PLAN.md（评审基线 rev0）+ proposal.rev1（实施基准，round1 复审后）+ decisions/FINDINGS（链 20260925-082315→083546）。日期 2026-09-25。夜间实施范围 = 可机器自主完成的部分；盲听轮（R1~R4）与 E1 归因回合执行留用户（D7/F1）。

## Problem Statement（用户视角）

用户要判断"影视剧配音：说话人克隆换声 + 翻译后，剧集背景音（配乐/环境/音效）能否高质量合成回去"这个研究方向是否可行。文献调研（docs/research/05）已给出技术地图，现在需要用真实素材做实验拿到可判 go/no-go 的证据。约束：这是纯研究旁车，主线（采访视频中文配音）的代码、片库、媒体、服务一行都不能动；测试视频也要独立获取，不碰主线的下载视频。

## Solution（用户视角）

在 `lab/drama/` 独立实验区落地六个实验的可自主部分：搜齐三轨素材（Blender 开源电影正片、B 站剧集、DnR 数据集）并按场景分层切片标注；建独立实验环境（.venv-lab，不碰主线 venv）；跑分离的客观指标（真值轨 SDR、bleed 指数、波形相减 vs 模型第二输出）；构造伪重叠集；制备 E1 三臂 ABX 试听包（听的部分留给用户，晨间 15~20 分钟/轮）；全部结果与结论写入 `lab/drama/REPORT.md`（夜间交付终点），升格正式调研报告与后续动作留给用户白天决定。

## User Stories

1. 作为研究者，我想要三轨素材就位（Blender 正片含 5.1 可得性核实、B 站两部剧、DnR 真值），以便分离实验既有真实域又有客观真值。
2. 作为研究者，我想要素材按场景分层切片并满足配额（每部剧每语言：对白干净/音乐重/音效压对白各≥3 段、双人重叠≥4 段），以便结论不被易样本偏置（F6）。
3. 作为研究者，我想要独立实验环境（.venv-lab + 复制的小工具 + GPU 探测落账），以便研究不碰主线任何环境（D1/D2，F3）。
4. 作为研究者，我想要首轮分离客观横评（mel_band_roformer 主力；波形相减背景床 vs 模型第二输出对比；真值轨 museval SDR；bleed 指数附 F4 sanity 校验），以便用数字而不是印象选配置。
5. 作为研究者，我想要伪重叠构造集（真实独白段按 SNR 0/±3dB 混合）与 TSE 冒烟脚本，以便 E2 有真值可评"提错人率"。
6. 作为研究者，我想要 E1 三臂 ABX 试听包（主臂=分离床+克隆配音回混；克隆对照臂=克隆声 vs 原声直比；分离对照臂=**实际分离所得背景床+原对白**——按 F1 复审修正版制备，标注待用户确认）与试次清单，以便晨间戴耳机 15~20 分钟拿到总闸数据。
7. 作为研究者，我想要 E3 时长三段式的脚本与首批统计（LLM 音节预算多候选→TTS speed→atempo；zh→en 与 en→zh 双向），以便量化"塞窗率"。
8. 作为研究者，我想要 E4 的 5.1 中置对照数据（若 Blender 5.1 核实到），以便判定"有 5.1 走中置"是否成立。
9. 作为研究者，我想要全部结果进 REPORT.md（provisional 标注 + 待决清单 + 晨间要决定的事），以便早上 10 分钟看懂全貌并拍板。

## Implementation Decisions

- **目录/环境**：`lab/drama/{PLAN.md(原稿,只读), PLAN.rev1.md(实施基准), REPORT.md, common/, tools/, e1_separation/, e2_overlap/, e3_timing_remix/, e4_center51/, results/, media/(gitignored), clips_manifest.yaml}`；`.venv-lab/`（gitignored）。公共小工具（ffmpeg 包装、srt 解析等）从主线**复制**进 common/，不 import boke。
- **素材**：Blender 正片走官方发布（制作分轨在订阅墙后，不依赖；5.1 发行版核实到才做 E4）；B 站剧选择权已下放（D6：1 部国产 + 1 部海外，免费可看，对话密集、含音乐重/音效压对白/重叠场景）；DnR test 从 Zenodo。媒体一律进 `lab/drama/media/`，独立脚本下载，不复用主线 B 站充电下载逻辑。
- **分离配置**：mel_band_roformer（audio-separator[gpu]，本机 3060 12GB）提人声；背景床 = 原混 − 人声（波形相减，audio-separator 默认行为）；与"模型 instrumental 输出"做对照量化。BandIt-v2 若时间允许作第二配置。
- **客观指标**：museval SDR/SI-SDR（真值轨）；bleed 指数 = Whisper 对背景轨听写可懂度/对原混可懂度，**首轮先验证与 SDR 的相关方向（F4）**再用于排序；非对白窗背景床与原混逐样本一致性（相减法应恒等）。
- **E1 三臂（制备侧）**：主臂与克隆对照臂照 rev1；**分离对照臂按 F1 修正版制备**（主臂实际分离背景床+原对白回混），并在产物与 REPORT 明标"F1 修正待用户确认"；ABX 试次清单 json（A/B/X 随机化）+ 听者说明落 `results/abx/`。判据口径按 F9 细化执行：**分档（50/65%）优先于显著性检验；闸门判定用总体试次，分层只做报告**（留晨间确认）。克隆 TTS：CosyVoice 装入 .venv-lab（若夜间装不通，则主臂管道用"原对白直通+分离床"先打通并如实记录，克隆版补于次日——不静默降质）。
- **伪重叠**：真实轨独白段（diarization 非重叠窗）两两混合 SNR {0,+3,−3}dB，同/异性别分层；TSE 冒烟候选 X-TF-GridNet（研究代码）或 NeMo tse_sortformer（重），环境装不动则交付"数据就绪+脚本就绪+冒烟待跑"并如实记录。声纹自检门冒烟用 speechbrain ECAPA（轻量）。
- **E3 时长**：脚本 + 小样本统计（无 LLM API 密钥时用本地预算规则先跑占位——如实标注），双向。
- **执行位置**：本机 3060 12GB（D8 已核实）；远端 3090x2 仅批量放大备用，不碰 4090x2 生产机。
- **夜间边界**：代码/文档/manifest/结果在夜链分支提交（commit --only 精确路径）；media 与 venv 不入库；不写 docs/research/06（F7）；主线零改动。

## Testing Decisions

- 每个实验脚本可重跑（幂等或显式 --force），产物路径固定进 results/，REPORT 引用数字必须能在 results/ 找到对应 json/md。
- 分离指标：真值轨上与 museval 官方输出对账一次（防自算错）；bleed 指数附 sanity 记录（无对白负例的 Whisper 幻觉率）。
- 试听包：每试次 A/B/X 三段等长、电平不露馅（响度配平后 true peak 校验），清单 json 与音频文件一一对应，脚本自检通过才算制备完成。
- 伪重叠集：每条记录两源段 id、SNR、性别分层；抽样 3 条人耳不可能（夜间无听者）→ 用能量交叉检查与波形对账代替。
- 不测实现细节；验收看外部行为（脚本跑通、指标落盘、REPORT 可读）。
